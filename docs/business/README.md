## اصول تفسیر

- **SOURCE:** گزاره‌ای که در طرح‌نامه آمده است؛ بازتاب نیت طراح سند، نه اثبات اجراپذیری یا تأیید حقوقی/بازاری آن.
- **APPROVED:** تصمیمی که کارفرما صریحاً در همین پروژه تأیید کرده است.
- **PROPOSED:** پیشنهاد طراحی برای بحث؛ تا تأیید، قرارداد نیست.
- **OPEN:** ابهام یا تعارض؛ اجرای وابسته به آن باید متوقف بماند.
- **NOT IMPLEMENTED:** این مخزن هنوز کد عملیاتی، پرداخت، مدل هوش مصنوعی یا اتصال حقیقی ندارد.

> ارجاع صفحات به شماره **صفحه فایل** است؛ شماره چاپی در سند معمولاً یک واحد کمتر است. اصل DOCX در GitHub بازنشر نشده است.

**برنامه مادر:** Business → Technical → Product Backlog → Sprint → Code → Code Review → Stage → QA/Testing → Release Approval → Production → Monitoring → Improvement.
